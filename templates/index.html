🌟 Auspify ML Internship Project Overview

Practical 4-week program deliverables built on the 8,807-title Netflix Movies and TV Shows dataset.

Task 1 NLP & Similarity

Content Recommendation System

  • Core Tech: TF-IDF (10,000 features), Cosine Similarity
  • Input: Weighted Content Soup (genres x2, cast, director, plot)
  • Speed: Sub-millisecond similarity lookup
  • Status: Validated across 5+ benchmark query sets
Task 2 Supervised Learning

Content Type Prediction Model

  • Core Tech: Logistic Regression, Decision Tree, Random Forest
  • Evaluation: 20% stratified holdout test split
  • Metrics: 99.7% Accuracy, 0.998 F1, 1.000 ROC-AUC
  • Leakage: Duration leakage strictly prevented
Task 4 Unsupervised Learning

Netflix Content Segmentation

  • Core Tech: K-Means, Elbow Method, Silhouette Analysis
  • Dimension: 2D PCA projection (41.2% variance explained)
  • Clusters: 5 distinct strategic catalog archetypes
  • Utility: Content acquisition & subscriber targeting
Task 6 Capstone Analytics

Content Success Analytics Engine

  • Core Tech: 5-Fold Stratified CV, KPI Synthesis
  • Predictive: International reach likelihood modeling
  • Insights: Format shift, global hub trends, turnover velocity
  • Deliverable: Executive visual dashboard
