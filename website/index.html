Task 1NLP & Similarity

Content Recommendation System

  • Model: TF-IDF Vectorizer (10,000 features, n-grams 1-2)
  • Metric: Cosine Similarity Matrix (linear_kernel)
  • Feature: Weighted Content Soup (genres x2, cast, director, plot)
  • Status: Benchmark tests verified
Task 2Supervised ML

Content Type Prediction Model

  • Models: Logistic Regression, Decision Tree, Random Forest
  • Holdout: 20% stratified test set
  • Score: 99.7% Accuracy, 0.998 F1, 1.000 ROC-AUC
  • Integrity: Duration formatting leakage prevented
Task 4Unsupervised ML

Netflix Content Segmentation

  • Algorithm: K-Means (optimal k=5 via Elbow & Silhouette)
  • Projection: 2D PCA (41.2% variance explained)
  • Output: 5 strategic audience archetypes
  • Application: Content commissioning & user targeting
